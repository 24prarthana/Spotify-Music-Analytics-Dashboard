# Spotify Music Analytics Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard designed to analyze Spotify music data and uncover insights into track popularity, artist performance, music genres, and audio characteristics.

The project transforms raw music data into meaningful insights through data cleaning, DAX calculations, and interactive visualizations.

## Dashboard Pages

### 1. Executive Overview
- Key performance indicators
- Top artists and tracks
- Genre distribution
- Interactive filters

### 2. Artist & Track Analysis
- Artist popularity analysis
- Top tracks by popularity
- Danceability vs. popularity
- Artist energy comparison

### 3. Audio Features Analysis
- Average danceability
- Average energy
- Acousticness and valence
- Audio feature comparisons across genres

### 4. Advanced Insights
- Explicit vs. non-explicit tracks
- Track popularity distribution
- Popular tracks percentage
- Genre popularity analysis
